# Contributing to TalaKlase

Thanks for helping improve TalaKlase.

Please keep changes small, readable, and backward compatible where possible.

Before opening a pull request:

- Read `AGENTS.md`
- Read `TESTING.md`
- Run the relevant PHP syntax checks
- Verify the affected workflow still works

Please avoid:

- Hard-coded secrets
- Breaking API or engine contracts
- Large refactors without a clear reason
